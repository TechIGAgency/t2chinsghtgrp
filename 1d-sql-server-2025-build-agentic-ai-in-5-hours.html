📘 Workshop Agenda (5 Hours)

  • Hour 1 — SQL Server 2025 for AI-Ready Data
    Configure SQL Server 2025, enable AI-assisted features, create vector-ready tables, and prepare enterprise data for semantic retrieval.
  • Hour 2 — Vector Embeddings & Semantic Search
    Generate embeddings, build a vector store, and implement cosine similarity search to power context-aware chatbot responses.
  • Hour 3 — Azure OpenAI + LangChain Agentic Chat Workflow
    Build an agentic chatbot that retrieves, reasons, and responds using your SQL Server data. Implement tool-calling and structured reasoning.
  • Hour 4 — Observability with OpenTelemetry
    Add tracing, logging, and performance insights to monitor your agentic workflow end-to-end and diagnose retrieval or model issues.
  • Hour 5 — Streamlit Chat UI + Deployment Pattern
    Build a production-ready chat interface, integrate the agentic workflow, and review deployment patterns for internal or customer-facing use.
